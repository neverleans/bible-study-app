# ADR 001 - SvelteKit

**Date:** 2026-09-27
**Status:** Accepted

## Context
We need a frontend framework that provides excellent performance, developer experience, and simple reactivity for the Bible study platform.

## Decision
Use SvelteKit with Svelte 5.

## Consequences
- **Pros:** Smaller bundle sizes, built-in routing, straightforward state management, fast learning curve.
- **Cons:** Smaller ecosystem compared to React.
